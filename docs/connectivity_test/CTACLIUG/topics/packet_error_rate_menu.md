# Packet Error Rate \(PER\) menu

The Packet Error Rate \(PER\) test mode is used to measure the sensitivity of the radio based on packet reception. The content of this menu is strictly related to the operation mode of the device.

PER test can be performed in three different modes:

1.  Transmission *without expected acknowledgement*.
2.  Transmission *with expected acknowledgement*.
3.  Transmission *with expected enhanced acknowledgement*.
