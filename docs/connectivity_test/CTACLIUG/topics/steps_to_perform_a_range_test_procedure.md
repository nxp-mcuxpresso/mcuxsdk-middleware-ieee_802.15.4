# Steps to perform a Range Test procedure

The steps to perform a Range Test procedure are as follows:

1.  Set the source and destination address of the transmitter device: `source=0xaaaa`, `destination=0xbbb`. \(Any other addresses can be chosen\). See the figure below.   <br>
**Range Test: Set the source and destination addresses on TX side**
    ![](../images/image4.png "Range Test: Set the source and destination addresses on TX side")

2.  Set the source and destination address of the receiver device.

    For example, `source=0xbbbb`, `destination=0xaaaa`. \(Any other addresses can be chosen\). See the figure below.<br>   
   **Range Test: Set the source and destination addresses on RX side**
    ![](../images/image5.png "Range Test: Set the source and destination addresses on RX side")

3.  Set the receiver device to run as shown in the figure below.   <br>
   **Range Test: Set the RX device to run**
    ![](../images/image13.png "Range Test: Set the RX device to run")

4.  Set the transmitter device to run.

    TX device CLI messages are shown in the figures below.   <br>
    **Range Test: TX device CLI messages**
    ![Range Test: TX device CLI messages](../images/image14.png "Range Test: TX device CLI messages")
    **TX device CLI messages**
    ![TX device CLI messages](../images/image15.png "TX device CLI messages")

5.  Receiver device CLI messages are as shown in the figure below.<br>     **Range Test: RX device CLI messages**<br>
