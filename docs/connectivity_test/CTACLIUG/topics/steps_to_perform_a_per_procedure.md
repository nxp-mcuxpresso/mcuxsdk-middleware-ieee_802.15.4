# Steps to perform a PER test

The steps to perform a PER test procedure are as follows:

1.  Set the source and destination address of the transmitter device. For example, `source=0xaaaa`, `destination=0xbbb`. \(Any other address can be chosen instead.\) See the figure below.   
**PER Test: Set source and destination addresses on TX side**
    ![](../images/image4.png "PER Test: Set source and destination addresses on TX side")

2.  Set the source and destination address of the receiver device. For example, `source=0xbbbb`, `destination=0xaaaa` \(Any other addresses can be chosen instead\). See the figure below.   
**PER Test: Set destination and destination addresses on RX side**
    ![](../images/image5.png "PER Test: Set destination and destination addresses on RX side")

3.  Set the receiver device to run.
4.  Set the transmitter device to run.
